# Inventory & Warehouse Management Dashboard

## Project Overview
The Inventory & Warehouse Management Dashboard is an interactive dashboard designed to analyze inventory levels, stock quantities, product performance, and warehouse operations. It helps users monitor inventory status, identify stock shortages, and make better inventory management decisions.

## Tools Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Visualization

## Key Performance Indicators (KPIs)
- **Total Inventory Value:** $332.65K
- **Total Stock Quantity:** 55K
- **Total Products:** 990
- **Total Reorder Quantity:** 51K

## Dashboard Features
- **Year, Quarter, and Month Filters:** Analyze inventory data across different time periods.
- **Inventory Value by Category:** Compare inventory value across product categories.
- **Inventory Turnover Rate by Category:** Identify categories with higher inventory turnover.
- **Product Status Analysis:** Monitor discontinued, active, and backordered products.
- **Top 10 Products by Stock Shortage:** Identify products with the largest stock shortages.
- **Sales Volume vs. Stock Quantity:** Compare product sales volume with available stock.
- **Stock Received Trend:** Track stock received across different months.

## Key Insights
- The dashboard provides an overview of inventory value and stock availability.
- Product categories can be compared based on inventory value and turnover rate.
- Stock shortages can be identified to support timely reordering.
- Product status analysis helps monitor active, discontinued, and backordered products.
- Monthly stock-received trends help track changes in warehouse inventory.

## Business Benefits
- Improves inventory monitoring and visibility.
- Helps identify stock shortages and potential reorder requirements.
- Supports data-driven inventory planning
